# 2.2.3 (2026-03-20)

- 修复：自定义平台 API 验证更准确，填写 Base URL 时不再误判为验证通过。
- 优化：原理图功能性审查速度更快，AI 能更高效地获取电路全貌。
- 优化：ERC/DRC 检查结果判断更准确，不再出现检查已通过但仍反复尝试获取详细结果的情况。

# 2.2.2 (2026-03-19)

- 新增：支持上传文档（.txt、.md、.csv 等纯文本格式）到聊天输入框，最多同时添加 10 个，AI 可直接读取文档内容。
- 移除：取消会话标题自动生成功能。
- 移除：取消思考模式开关。

# 2.2.1 (2026-03-18)

- 优化：AI 在原理图中放置器件时，会自动将器件布局在图纸中心区域，不再出现摆到边角或超出红框的情况。
- 优化：AI 放置完器件后会自动完成所有引脚的电气连接，不再留悬空引脚要用户手动补线。
- 新增：用户说检查原理图时，AI 默认进行功能性审查（分析电路用途、器件选型、引脚连接、能否正常工作），只有明确说跑 ERC 或做 DRC 时才执行规则检查。

- 移除：去掉百度文心一言预置平台，用户仍可通过自定义平台自行接入。
